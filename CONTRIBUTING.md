# Contributing

1. Fork the repository and branch from `main`.
2. Read `AGENTS.md` before changing API, state, or build behavior.
3. Use fictional names and private-network example addresses in code, docs, and screenshots.
4. Run `./gradlew clean compileDebugKotlin lintDebug assembleDebug`.
5. Include manual UI checks in the pull request.

Never commit `local.properties`, APK signing material, live family data, or private network addresses.
